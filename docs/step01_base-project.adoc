== step01: 元となる静的HTMLサイト

link:https://github.com/kazurayam/how-to-setup-vite-not-to-hash-ID-in-CSS-selector/blob/master/base-project/index.html
[レポジトリ]をローカルにcloneして、`base-project/index.html`` を開くと、以下のような静的HTMLサイトが表示されます。

image:{PAGES_URL}/images/011_base-project.png[base-project/index.html]

どおってことないwebサイトです。HTMLとCSSと画像から構成されています。

[source.shell]
----
$ tree base-project
base-project
├── images
│   └── seagull.jpg
├── index.html
└── style
    ├── general.css
    ├── index.css
    └── layout.css
----

ソースコードを掲載しておきます。

=== index.html

[source,html]
----
include::../base-project/index.html[]
----

=== style/general.css

[source,css]
----
include::../base-project/style/general.css[]
----

=== style/layout.css

[source,css]
----
include::../base-project/style/layout.css[]
----

=== style/index.css

[source,css]
----
include::../base-project/style/index.css[]
----

ここに登場したCSSセレクタに注目してください。

`#main .mainVisual`
